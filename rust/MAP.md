# Seraphine 整应用 Rust 迁移地图

目标：用 Rust 重写 Seraphine 全部功能（Tauri 外壳 + Rust 业务核心 + React 前端），功能等价于 Python 版，旧版保留为回退，直至全部硬门槛通过。

决策：见 [DECISIONS.md](DECISIONS.md)。术语：见 [GLOSSARY.md](GLOSSARY.md)。移植规则：见 [RULES.md](RULES.md)。

- 签名证书与 Tauri updater 密钥的保管方式。
- OP.GG 图标资源是否继续缓存到 `%LOCALAPPDATA%/Seraphine`（与旧版共享只读）。
- 是否需要保留 `seraphine-sidecar` 作为第三方调用接口。
